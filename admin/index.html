Everything, explained.

A short reference for how the console maps to what visitors actually see.

Editing text

Every card in the Homepage / Grit / Kitchen / Smoothies / Snacks tabs already shows exactly what's live right now — the badge tells you Published or Draft plus which section it's from. Click Edit ↗ to open it with every field prefilled. Nothing opens blank, and closing without saving changes nothing.

Set the toggle to Draft to hide something from the live site without deleting it — the page falls back to showing nothing for that field until you publish it again.

Etsy drops carousel

Unlike the other sections, the Etsy Drops carousel is a free-form list, not fixed cards — add, remove, publish, or unpublish items from the Image Studio tab and the number of items on the live site changes to match. Use placement Etsy drops carousel — add an item when uploading.

Replacing an existing photo

For the Hero, Travel, Creator, and Tap In photos, pick the matching placement in the Image Studio's dropdown and leave the filename field filled in with the current file it should replace (each option shows which one). That swaps every place on the site using that photo at once.

Product photos (leggings, hats, hoodies, etc.) use their own color-swatch buttons on the live site and aren't part of the Image Studio.

If something looks wrong

Every save and upload shows a message right on the form — green for success, red for an error. If you ever see a red message, nothing was lost; fix what it's pointing at and try again.
